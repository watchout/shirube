## 性能・容量・停止の予算

U2 は常駐サービスでなく、対話の中で 1 回ずつ実対象を読む。根拠のある p95・スループット・稼働率の目標は要件に無いため置かない。観測の停止予算（1 取得の時間・総時間・最大回数・1 応答の大きさ・自動再試行 0）は共通の profile の値を参照し、ここへ複製しない。ローカル file の読取りと子 process の起動にも同じ予算の枠組みを当てる。この予算は停止の条件であり、全処理の遅延や CPU・memory の保証ではない。実際の処理時間・要求数は後段で版と測定方法を添えて確かめ、未計測の性能を適合済みとしない。
