A. 半分の判定は、どちらの期間も「PR を開いてから統合まで」で比べる。意図の記録から統合までの時間は、記録がある PR について別に測って載せる
B. 入れた後は意図の記録から測り、今の値（PR を開いた時点から）とそのまま比べる（入れた後の方が長く出やすい）

（arc の勧め: A。比べる 2 つの期間を同じ物差し（PR を開いてから統合まで）にしないと、「半分になったか」が測り方の違いで動く（リード規律 L6: 測度を動かして達成に見せない）。B は入れた後の方が長く出て公平でなく、C は 101 件の起点を作業指示から探し直す手間が大きい）
