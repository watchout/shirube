- 意図 → 範囲 → バックログが食い違っていないか
- 範囲の各項目に、実現性の裏づけがあるか

## 意図 → 範囲

| 意図の記録 | 範囲での扱い | 結果 |
|------------|--------------|------|
| 対象は社内のすべての製品 | 最初の版は Shirube・AUN・Onza。残りは次の段階・再開後（OUT-1〜3） | 一致（段階を分けた） |

| やらないこと 3 つ | OUT-5〜7 | 一致 |

## 範囲 → 実現性の裏づけ

| 範囲 | 実現性の評価での裏づけ | 結果 |
|------|------------------------|------|
| IN-1 計測 | 主な指標 2 つは高い〜中程度、見張りは中程度〜低い | 裏づけあり（見張りの「誤って止めた回数」は仮説 A3 に依る） |
| IN-2〜IN-5 門 | 「最初に解く」の行（中程度）、配布キットは report-only、必須検査は Owner の決定 | 裏づけあり |
| IN-6 ずれの検査 | 「最初に解く」の行（中程度） | 裏づけあり |
| IN-7 誤って止めた件の記録 | 見張りの行（低い〜中程度）、仮説 A3 | 裏づけあり（仮説つき） |
| IN-8 作者の手間 | 実現性の評価では個別に見ていない | 注意: 範囲の段で S1-SH-05 として加わったため、実現性の評価には無い |
| IN-9 Shirube 自身が門を通る | 実現性の評価では個別に見ていない | 注意: 範囲の段で S1-SH-06 として加わったため、実現性の評価には無い |

## 結果

- 意図 → 範囲 → バックログ: 食い違いなし。
- 実現性の裏づけ: 10 項目中 7 項目は裏づけあり、3 項目（IN-8・IN-9・IN-10 の Onza 分）は実現性の評価で個別に見ていない。止めるほどの食い違いではないが、要件定義で確かめる。
